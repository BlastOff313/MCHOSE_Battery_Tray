# MCHOSE Battery Tray

Небольшая программа для Windows, которая показывает заряд поддерживаемых беспроводных гарнитур MCHOSE прямо в области уведомлений рядом с часами, звуком и сетью. Для чтения используется только read-only HID-запрос к USB-приёмнику 2,4 ГГц. Держать MCHOSE HUB открытым не требуется.

**Лицензия:** [MIT](LICENSE) — свободное использование, изменение и распространение, в том числе в коммерческих проектах, при сохранении уведомления об авторских правах и текста лицензии.

> **Важно о совместимости:** это пока не универсальный драйвер для всех гарнитур MCHOSE. Сейчас поддерживается несколько ID приёмников, использующих общий старый протокол `FF90:0001`. У других моделей протоколы отличаются; они будут обозначаться как неподдерживаемые, пока для них не появится отдельная реализация.

## Возможности

- Процент заряда в системной области уведомлений Windows.
- `F+` в значке при полном заряде (100%).
- `×`, когда гарнитура явно отключена, приёмник отсутствует или два раза подряд не удалось получить ответ.
- `?`, если Windows видит аудио/HID-устройство MCHOSE, но программа пока не может получить достоверный процент (неподдерживаемый протокол или режим зарядки без свежего значения).
- Компактный значок в стиле Windows 11: Bahnschrift Bold, цвет подстраивается под светлую/тёмную панель задач.
- Автообновление раз в 60 секунд и ручное обновление через меню значка.
- Необязательный автозапуск с Windows.
- Локальный журнал. Программа не использует облако, телеметрию или сетевые запросы.

## Совместимость

### Реализован общий старый HID-протокол

Для перечисленных ниже ID приёмников используется один read-only обмен (`FF90:0001`, выходной отчёт `55 65 01`, ответ `55 65 <заряд> <состояние>`):

| Семейство / модель гарнитуры | VID:PID USB-приёмника | Статус данных |
|---|---:|---|
| MCHOSE X9 | `3837:6045` | Проверено автором проекта на Windows 11 |
| MCHOSE V9 Pro | `291D:385D` | Протокол проверен сообществом на реальном устройстве |
| Семейство V9 / V9 Pro | `41E4:3201`, `41E4:3202` | Описание по M HUB / данным сообщества; автором проекта независимо не проверено |
| MCHOSE G9 Pro | `41E4:3502` | Описание по M HUB / данным сообщества; автором проекта независимо не проверено |
| MCHOSE S9 Pro | `41E4:3402` | Описание по M HUB / данным сообщества; автором проекта независимо не проверено |
| Семейство V9 Turbo / V9 Turbo+ | `3837:600D`, `3837:600A`, `3837:6009` | Описание по M HUB / данным сообщества; автором проекта независимо не проверено |

Нужен USB-приёмник и режим **2,4 ГГц** на гарнитуре. Чтение заряда через Bluetooth этой реализацией не поддерживается.

### Пока не реализовано / нужны дополнительные данные

- **V9 Pro 2 (`3837:6011`)**: использует другой HID-интерфейс (`FF07:0222`) и отдельный кадр батареи `0x55 / 0x0B`. Эта версия намеренно не отправляет запросы по этому протоколу, так как отдельный парсер ответа ещё не реализован.
- **R9, S9, G9 (не Pro) и другие варианты**: пока нет достаточно проверенной карты ID приёмника и протокола. Если Windows видит аудио-устройство MCHOSE, но ID приёмника или протокол неизвестен, появится `?`, а не ложное сообщение об отключении или выдуманный процент.
- Подключение только по Bluetooth и проводной аудиорежим не поддерживаются HID-ридером.

Совместимость зависит от конкретной аппаратной версии приёмника и прошивки, а не только от названия гарнитуры. По одному названию модели нельзя гарантировать работу.

## Запуск

1. Скачайте ZIP и распакуйте его.
2. Запустите `start.vbs` для тихого запуска или `start-debug.cmd`, чтобы видеть ошибки PowerShell.
3. Значок появится в области уведомлений Windows. Если он спрятан за стрелкой `^`, откройте **Параметры → Персонализация → Панель задач → Другие значки в области уведомлений** и включите MCHOSE Battery Tray либо перетащите значок из скрытой области на панель.
4. Нажмите правой кнопкой по значку, чтобы обновить данные, включить/отключить автозапуск, открыть журнал или выйти.

Установка и права администратора не требуются. Используется Windows PowerShell 5.1, встроенный в Windows 10/11.

## Значки состояний

| Значок | Значение |
|---|---|
| `0`–`99` | Последний успешно полученный процент заряда |
| `F+` | Полный заряд; последний отчёт показал 100% |
| `×` | Гарнитура отключена / нет приёмника / два последовательных тайм-аута |
| `?` | Устройство MCHOSE видно в Windows, но достоверный процент пока недоступен (неподдерживаемый протокол или режим зарядки) |

После одного неудачного опроса значок не переключается сразу на `×`: программа ещё один цикл сохраняет последнее успешное значение, чтобы не мигать из-за кратковременного сбоя USB/HID.

## Безопасность и приватность

- Программа отправляет только read-only запрос заряда на явно перечисленные ID USB-приёмников. Неизвестные Product ID не опрашиваются; имена PnP-аудиоустройств используются только для отличия подключённой, но пока неподдерживаемой гарнитуры от отсутствующей гарнитуры.
- Неизвестным Product ID vendor-команда не отправляется.
- Настройки наушников, эквалайзер, прошивка и сопряжение не меняются.
- Нет сетевых запросов, аналитики и телеметрии.
- Журнал хранится локально: `%LOCALAPPDATA%\MCHOSE_X9_BatteryTray\tray-v9.log`.

## Как помочь с поддержкой других моделей

Если ваша гарнитура MCHOSE пока не поддерживается, создайте Issue и приложите:

- Точную модель и аппаратную ревизию.
- Тип подключения: USB-приёмник 2,4 ГГц, Bluetooth или USB-кабель.
- VID:PID приёмника из Диспетчера устройств Windows → Свойства → Сведения → ИД оборудования.
- Журнал `%LOCALAPPDATA%\MCHOSE_X9_BatteryTray\tray-v9.log`.
- Видит ли MCHOSE HUB гарнитуру в режиме 2,4 ГГц.

Не публикуйте серийные номера и персональные данные. Добавления новых протоколов должны быть ограничены точными ID приёмника и read-only командами.

## Источники и исследование протоколов

- [Официальная инструкция MCHOSE по ПО для игровых гарнитур](https://support.mchose.store/hc/en-us/articles/52492201202324-Gaming-Headset-Software-Guide) — актуальные семейства гарнитур для M HUB и требования к подключению 2,4 ГГц.
- [Официальные инструкции MCHOSE](https://www.mchose.store/pages/user-manual) — перечень моделей гарнитур.
- [OpenMHub: список совместимых устройств](https://github.com/brayanspagnol/OpenMHub) — общественная карта ID приёмников V9 / V9 Pro / G9 Pro / S9 Pro / X9 / V9 Turbo и общий старый протокол; в источнике часть ID помечена как непроверенная.
- [Device-Battery-Info: заметки о протоколах](https://github.com/PyFlat/Device-Battery-Info/blob/main/AGENTS.md) — проверенный владельцем обмен для V9 Pro (`291D:385D`).
- [BatteryHub: список совместимых устройств](https://github.com/krisgfx9/Wireless-Device-Battery-Monitor) — отдельный протокол V9 Pro 2 (`3837:6011`), который здесь пока не реализован.

Проект независимый и не связан с MCHOSE. MCHOSE — товарный знак его владельца.
