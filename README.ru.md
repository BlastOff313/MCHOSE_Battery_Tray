# MCHOSE Battery Tray


## Редакции и загрузки

Выбери удобный способ использования:

| Редакция | Загрузка | Описание |
|---|---|---|
| **Windows Installer v10.0.2** (рекомендуется) | [Скачать со страницы Releases](https://github.com/BlastOff313/MCHOSE_Battery_Tray/releases/latest) | Нативная программа .NET для Windows, установщик, необязательный автозапуск, ограничение журналов и штатное удаление. |
| **Portable v9.0** (legacy) | [Скачать Portable ZIP](https://github.com/BlastOff313/MCHOSE_Battery_Tray/releases/latest/download/MCHOSE-Battery-Tray-Portable-v9.0.zip) | Без установки. Распакуй ZIP и запусти `start.vbs`. Используется встроенный Windows PowerShell 5.1. |

Портативная редакция сохранена для тех, кто предпочитает запуск без установки. Это устаревшая кодовая база v9.0; в ней **нет всех улучшений v10.0.2** (в частности, ограничения журнала до 500 строк и отдельной идентичности нативного .NET-приложения). Для новой установки рекомендуем Windows Installer.

**Важно:** не запускай Portable и Installer одновременно. Закрой одну редакцию перед запуском другой, чтобы не получить два значка и конкурирующие HID-опросы.


## Последнее исправление — v10.0.2

Укреплён HID-обмен: чтение входящих отчётов и отправка команды используют отдельные дескрипторы и экземпляры `FileStream`. Программа отслеживает входящий ответ и завершение записи параллельно, не ожидая завершения `WriteAsync` перед проверкой батарейного отчёта. Это позволяет принять корректный ответ, даже если HID-драйвер задерживает подтверждение записи. В журнал добавлена отметка, если процент получен до завершения записи. Также сохранён исправленный механизм отрисовки значка через `Graphics.DrawString` из v10.0.1. Изменение требует проверки на реальном USB-приёмнике MCHOSE X9.

Небольшая нативная программа для области уведомлений Windows, показывающая заряд поддерживаемых беспроводных наушников MCHOSE. Общается с совместимыми USB-приёмниками 2,4 ГГц через read-only HID-запросы. Держать MCHOSE HUB открытым не требуется.

> **Важно о совместимости:** программа не является универсальным драйвером для всех наушников MCHOSE. Совместимость зависит от конкретной аппаратной ревизии USB-приёмника и его прошивки. Неизвестным VID:PID программа не отправляет команды производителя.

## Возможности

- Процент заряда непосредственно в области уведомлений Windows.
- Плавный цветовой градиент **приглушённый красный → мягкий белый → приглушённый зелёный**: низкий заряд красный, около 50% белый, высокий зелёный.
- `F+` при заряде 100%.
- `×`, когда гарнитура явно отключена, приёмник отсутствует или два последовательных запроса заряда завершились тайм-аутом.
- `?`, когда физическое устройство MCHOSE обнаружено, но его протокол пока не поддерживается, либо во время зарядки нет достоверного текущего процента.
- Компактный значок в стиле Windows с Bahnschrift Bold и контуром, сохраняющим контраст в светлой и тёмной теме.
- Автообновление раз в 60 секунд и ручная команда «Обновить сейчас».
- Необязательный запуск вместе с Windows.
- Необязательный диагностический журнал: по умолчанию включён при первом запуске, отключается в меню значка.
- Ограничение журнала: **500 строк**. Активный файл сокращается после каждой записи; одна запись ограничена 4 096 символами; старые файлы удаляются через **14 дней**.
- Собственный нативный процесс `MCHOSE.BatteryTray.exe` с названием **MCHOSE Battery Tray**, а не хост Windows PowerShell 5.1.
- Самодостаточный установщик Windows: отдельно устанавливать .NET не нужно.
- Регистрация в **Параметры Windows → Приложения → Установленные приложения** и стандартное удаление.
- Нет облачной учётной записи, телеметрии и сетевых запросов приложения.

## Совместимость

### Реализован legacy HID-протокол

Следующие ID приёмников привязаны к одному документированному сообществом read-only обмену (`FF90:0001`, выходной отчёт `55 65 01`, ответ `55 65 <battery> <state>`):

| Семейство / модель | VID:PID USB-приёмника | Статус данных |
|---|---:|---|
| MCHOSE X9 | `3837:6045` | Проверено владельцем проекта на Windows 11 |
| MCHOSE V9 Pro | `291D:385D` | Есть отчёт сообщества о проверке на устройстве |
| Семейство V9 / V9 Pro | `41E4:3201`, `41E4:3202` | Данные M HUB / сообщества; проектом отдельно не проверено |
| MCHOSE G9 Pro | `41E4:3502` | Данные M HUB / сообщества; проектом отдельно не проверено |
| MCHOSE S9 Pro | `41E4:3402` | Данные M HUB / сообщества; проектом отдельно не проверено |
| Семейство V9 Turbo / V9 Turbo+ | `3837:600D`, `3837:600A`, `3837:6009` | Данные M HUB / сообщества; проектом отдельно не проверено |

USB-приёмник должен быть подключён, а наушники переведены в режим **2,4 ГГц**. Чтение заряда через Bluetooth и проводное аудио в этой версии не поддерживается.

### Пока не реализовано / нужны дополнительные данные протокола

- **V9 Pro 2 (`3837:6011`)**: использует другую HID-коллекцию (`FF07:0222`) и другой кадр батареи `0x55 / 0x0B`. Парсер пока не реализован.
- **R9, S9, G9 без Pro и другие варианты**: пока нет достаточно проверенной привязки приёмника и протокола. Если физическое устройство MCHOSE обнаружено, но профиль заряда неизвестен, программа показывает `?`.
- Подключение только по Bluetooth и проводной режим аудио не поддерживаются считывателем батареи.

Одного названия модели недостаточно для гарантии совместимости. Добавлять новые профили следует только для точных ID приёмника и подтверждённых read-only команд.

## Установка

1. Закрой старую PowerShell-версию MCHOSE Tray, чтобы после обновления не отображались два значка.
2. Скачай `MCHOSE-Battery-Tray-Setup-10.0.2.exe` со страницы **Releases** репозитория на GitHub.
3. Запусти установщик. Программа устанавливается в профиль текущего пользователя; права администратора не требуются.
4. При желании отметь **Start MCHOSE Battery Tray when I sign in to Windows**.
5. Программа появится в области уведомлений. Если Windows сначала скрыла её за стрелкой `^`, открой **Параметры → Персонализация → Панель задач → Другие значки в области уведомлений** и включи **MCHOSE Battery Tray**, либо перетащи значок в видимую область.

Программа работает как отдельный EXE с собственными метаданными продукта и AppUserModelID. Она больше не запускается внутри Windows PowerShell 5.1. Метаданные EXE и AppUserModelID процесса установлены как **MCHOSE Battery Tray**, поэтому Windows получает имя приложения вместо общего имени PowerShell. Точное отображение стоит проверить на разных сборках Windows 11.

Установщик пока не подписан сертификатом Authenticode. Для новой сборки SmartScreen может показать предупреждение о репутации.

### Удаление

Открой **Параметры → Приложения → Установленные приложения**, найди **MCHOSE Battery Tray** и выбери **Удалить**. Установщик также создаёт ярлык в меню «Пуск». При удалении программа и её запись автозапуска удаляются. Пользовательские настройки и журналы в `%LOCALAPPDATA%\MCHOSE\Battery Tray` намеренно сохраняются.

## Меню значка

Нажми правой кнопкой мыши на значок, чтобы:

- Обновить заряд вручную.
- Включить или отключить запуск вместе с Windows.
- Включить или отключить диагностический журнал.
- Открыть или очистить журнал.
- Закрыть программу.

## Журнал и автоматическая очистка

При первом запуске журнал включён. Отключи **Вести диагностический журнал** в контекстном меню, чтобы прекратить все дальнейшие записи. Настройка сохраняется между запусками.

- Текущий журнал: `%LOCALAPPDATA%\MCHOSE\Battery Tray\Logs\app.log`
- Максимальный размер активного журнала: 500 строк. При превышении лимита файл сокращается до последних 500 строк после записи. Одна запись ограничена 4 096 символами.
- Срок хранения: старые файлы `*.log*` старше 14 дней удаляются при запуске и во время периодической очистки. Если активный журнал не обновлялся более 14 дней, его содержимое очищается.
- Настройки: `%LOCALAPPDATA%\MCHOSE\Battery Tray\settings.json`

При отключённом журналировании диагностические события не добавляются. Проверка срока хранения и ограничение старого журнала при старте всё равно выполняются.

## Сборка из исходников

Требования:

- Windows 10/11 x64 для сборки.
- .NET 10 SDK.
- Inno Setup 6.

Запусти PowerShell в корне репозитория:

```powershell
.\build.ps1
```

Скрипт публикует самодостаточное однофайловое приложение и собирает Inno Setup пакет в `dist\MCHOSE-Battery-Tray-Setup-10.0.2.exe`.

GitHub Actions workflow `.github/workflows/build-installer.yml` запускает сборку вручную (`workflow_dispatch`) или при отправке тега `v*`. Для публичного релиза отправь тег, например `v10.0.2`: workflow соберёт GitHub Release и приложит установщик.

Проект использует **.NET 10 LTS**, поддержка которого продолжается до ноября 2028 года. <https://dotnet.microsoft.com/en-us/platform/support/policy>

## Безопасность и приватность

- Программа отправляет только read-only запрос заряда на явно перечисленные USB VID:PID.
- Неизвестным ID приёмников команды производителя не отправляются.
- PnP/WMI используется только для различения подключённого, но неподдерживаемого физического устройства MCHOSE и отсутствующего приёмника; сохранённые программные аудио-endpoint игнорируются.
- Настройки наушников, эквалайзер, прошивка и сопряжение не изменяются.
- Нет сетевых запросов, аналитики и телеметрии.
- Журнал хранится локально и может быть отключён в любой момент.

## Сообщения о совместимости

Если твоя модель MCHOSE не поддерживается, создай issue и приложи:

- Точную модель и аппаратную ревизию.
- Режим подключения: USB-приёмник 2,4 ГГц, Bluetooth или USB-кабель.
- VID:PID приёмника из Диспетчера устройств → Свойства → Сведения → ИД оборудования.
- Журнал `%LOCALAPPDATA%\MCHOSE\Battery Tray\Logs\app.log` (если журналирование включено).
- Видит ли MCHOSE HUB гарнитуру в режиме 2,4 ГГц.

Не публикуй серийные номера и личные данные. Новые профили протокола должны быть привязаны к точным ID приёмника и read-only командам.
