# MCHOSE Battery Tray — Portable Edition (Legacy v9.0)

Это последняя портативная редакция на PowerShell. Распакуй ZIP и запусти `start.vbs`. Используется Windows PowerShell 5.1, встроенный в Windows 10/11. Установщик, права администратора, .NET SDK и сторонние среды выполнения не нужны.

Для актуальной нативной программы рекомендуем **Windows Installer v10.0.2** из основного релиза. Portable v9.0 сохранена для тех, кто предпочитает запуск без установки, но в ней нет всех улучшений v10 (включая ограничение и срок хранения журналов и нативную идентичность .NET-приложения).

## Запуск
1. Распакуй ZIP в обычную папку.
2. Дважды щёлкни `start.vbs` для запуска без окна консоли.
3. Запусти `start-debug.cmd`, чтобы увидеть ошибки в консоли.
4. Значок появится в области уведомлений Windows. Если он скрыт, включи его в настройках значков панели задач.
5. Нажми правой кнопкой на значок, чтобы обновить заряд, настроить автозапуск, открыть журнал или выйти.

## Совместимость
Нужен USB-приёмник и режим 2,4 ГГц. Bluetooth-only и проводное аудио не поддерживаются. Совместимость зависит от точного ID аппаратной версии приёмника; неизвестным ID команды производителя не отправляются. Таблица проверенных/документированных приёмников находится в основном [README](../README.ru.md).

## Примечания
- Не запускай Portable и Installer одновременно.
- Журнал: `%LOCALAPPDATA%\MCHOSE_X9_BatteryTray\tray-v9.log`.
- В этой legacy-редакции нет ограничений размера/срока хранения журналов из v10.
